## Mechanism fixed (diagnosis recorded in the commit message)

(a) perf-evidence gap treated as failure with no stated reason, plus (b) a
capability pointer that ignored the registry's own boolean column. Level-0 bars
demanded at-median measured evidence in guard (175 rows) / review (133 rows) over
776 models, so unmeasured lanes fell to BLANK -1 and the profile collapsed onto
two carriers; with commandcode health-DOWN that was one hop. vision >= 1 now
resolves to the lane's own evidenced boolean (stored on models.jsonl, published
on /v1/models) with TR-369's three-state contract, and one `_split_requirements`
is shared by chain build, `requirements_unmet` and the report so the surfaces
cannot disagree. P4's guard/review bars moved 0 -> -1 in
data/tables/task_profile_requirements.jsonl (load-bearing requirement stays
security >= 2); null_reasons.jsonl gained three no-sample-yet stamps for lanes
whose review has no evidence row at all. No literal model names were added to
code or tables (verified by grep over the commit diff).
