## Failure found and fixed during this tick

First hosted run (`42109709029`) failed with 4 order-dependent failures:
`test_cli_paths` (3) and `test_quota_gate` (1) asserted their own tmp home but
observed `/tmp/tr369-state-ae50r9ck`. Cause: the new test module called
`os.environ.setdefault("ROUTER_STATE_DIR", tempfile.mkdtemp(...))` at IMPORT
time, and pytest imports every module during collection before running any
test — so the value leaked into every later module. Fixed in 0ecb7f2 by
removing the ambient mutation; `ROUTER_STATE_DIR` is already set per-subprocess
inside the census test, the only place it is needed. Proven by running the four
modules in one session: 92 passed.
