## 6. Operations an agent should NOT be given, and how they are withheld

`endLedger`, `ingestOutcome`, `updateProviderListing`, `updateModelListing`,
`updateProfileListing`). muster generates a tool/command for every operation —
visibility is muster's contract; **the server, not the client, is the gate**
(`RouterApplication._authorize` answers before any handler). Read-only mode
refuses every mutation with `403 {"error": "read-only mode"}` before any
handler runs; the production instance runs read-only. Proven live through
BOTH muster surfaces this run:

  contains `HTTP 403` + `read-only mode`, and `GET /circuit/status`
  (jq-normalized, `del(.ts)`) was sha256-identical before/after — state
  untouched, not merely refused. (`fb00b306fe42…` in the run log.)

  probe-model --outcome failure --reason tr128-cli-probe`): rc=1,
  `error  read-only mode` / `Error: HTTP error: 403 Forbidden`.
